# Agent Instructions

## Constitution And Project Charter

Before planning or implementing work in this repository, read `PROJECT_CHARTER.md`.
It inherits the Kinelo Company Constitution at
`Youngkwon-Lee/second-brain@main:company/KINELO_CONSTITUTION.md`.

The local charter is the first authority for this repository's role, ownership,
non-ownership boundaries, validation gate, and stop conditions. If a requested
task conflicts with the charter or would move authority into this repository
from another owner, stop and route the decision upward instead of implementing
around the boundary. A faster agent or automation does not gain broader
authority.

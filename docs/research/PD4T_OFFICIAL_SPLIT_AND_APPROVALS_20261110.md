# PD4T 공식 분할 기준과 사용 승인 기록 (2026-11-10)

## 1. 논문·비교 실험의 기준 분할

- **기준:** PD4T 원 논문(PECoP/PD4T)의 **22 train / 8 test subject 분할**.
  PD4T 배포본의 과제별 `Annotations/<Task>/train.csv`, `Annotations/<Task>/test.csv`가 이 분할을 정의한다.
- **결정 근거:** 12차 회의(2026-09-22 이전)에서 원 논문 분할과 지표로 재실험하기로 결정,
  13차 회의(2026-09-22)에서 이 분할로 재학습한 결과를 논문용 benchmark 기준으로 채택.
- **14차 회의(2026-10-20) 실험은 이 공식 분할 test set으로 수행했다.**
  Gait test 116 clips, seed 42 기준:

  | 조건 | QWK (95% CI) | exact | MAE |
  | --- | --- | --- | --- |
  | C0B | 0.584 (0.459–0.682) | 0.534 | 0.491 |
  | C0BH | 0.510 (0.348–0.635) | 0.500 | 0.560 |
  | C2B | 0.537 (0.385–0.657) | — | — |
  | C2BH | 0.452 (0.274–0.592) | 0.500 | 0.578 |

  단일 seed 결과이며 신뢰구간이 겹친다. 3-seed 반복 결과는 15차 회의(2026-11-12)에서 갱신 예정.

## 2. 쓰지 않는 이전 분할

다음은 원 논문 test 대상자와 겹치거나(13차: 원 논문 test 참여자 4명, 약 60개 영상이 기존 학습 집합에 포함)
원 논문과 직접 비교할 수 없는 **이전 Hawkeye 자체 분할**이다. 원 논문과의 비교·논문 수치에는 사용하지 않는다.

- `scripts/fix_data_split.py`, `scripts/fix_data_split_stratified.py`로 만든 subject-level 재분할
- `Annotations_split` 기반 수치(`docs/PD4T_DATASET.md`의 split 통계 표)
- `docs/PD4T_TEST_SET_REPORT.md`의 19명 test set
- Notion "PD4T 데이터 Split (Stratified)" 페이지의 분할

이 파일들은 기록 보존을 위해 그대로 둔다.

## 3. 사용 승인 상태

- **PD4T 연구 사용:** 승인됨 (프로젝트 책임자 확인, 2026-11-10).
- **ICT GPU 사용:** 허가됨 (프로젝트 책임자 확인, 2026-11-10).

이 기록은 승인 사실의 메모다. 재학습 코드(PR #37)의 실행 게이트가 요구하는 manifest·승인 영수증 입력을
대신하지 않으며, 해당 게이트는 실행 시 별도로 채운다.

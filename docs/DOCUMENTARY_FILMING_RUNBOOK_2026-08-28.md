## 촬영 순서

### 1. HawkEye 분석 비교 — 5초

- 화면: `/filming-demo`
- 시작 상태: 자동 반복 재생, 재생 위치 00:00.0
- 구도: 주소창을 제외하고 `원본 영상`과 `관절 추적 결과`가 모두 보이게 촬영
- 내레이션 포인트: “같은 프레임에서 관절 위치와 움직임을 비교합니다.”
- 이어지는 화면: 아래로 한 번 스크롤해 `관절 각도 변화`와 `동작 속도 변화`를 3초 촬영
- 금지: 실제 환자 영상, 임상 점수, 이름, 검사 ID

### 2. Kinelo Ops — 3초

- 보여줄 것: 작업 상태가 `라벨링 → 검토 → 학습 전달`로 이동하는 한 장면
- 사용할 항목: 촬영용 데모 프로젝트/가상 항목만 사용
- 구도: 중앙 작업 영역만 촬영하고 브라우저 주소창·좌측 계정 영역은 제외
- 금지: 이메일, 실제 구성원 이름, 내부 URL, 토큰, 환자/데이터셋 원본 파일명
- 데모 프로젝트가 준비되지 않았으면 실제 화면을 촬영하지 않고 HawkEye 화면으로 대체

### 3. Notion — 3초

- 보여줄 것: `연구 협업 흐름` 제목과 아래 네 단계만 보이게 정리
  1. 라벨링 데이터 생성
  2. 엔지니어 검토·학습
  3. 모델 서빙·추론 적용
  4. 결과 검토 후 지속 업데이트
- 구도: 본문만 촬영하고 워크스페이스 사이드바·주소창·공유 대상은 제외
- 금지: 계정 이름, 이메일, 비공개 페이지 제목, 내부 링크, 댓글 알림

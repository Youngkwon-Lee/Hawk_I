# KHF 발표 대본 — 암기용 구성안

> 기준: 작년 Hawk Eye 발표 대본의 말투와 순서
>
> 구성: **임상 문제 → 주제 선정 → 데이터셋 → 분석 → 결과 → 시연 → 결론**
>
> 사용법: 문장을 전부 외우지 말고, 각 슬라이드의 **굵은 핵심 문장 하나**와 다음 슬라이드로 넘어가는 흐름만 기억한다.
>
> 주의: ODD/ASD 내용은 제외한다. 현재 결과의 수치는 8월 13일 PPT 기준이며, 최종 발표 전 영빈 선생님과 다시 확인한다.

## 발표를 관통하는 6개 문장

1. **임상에서 움직임의 변화는 보이지만, 수치로 남기기 어렵습니다.**
2. **그래서 영상 기반 정량 평가와 설명가능 AI를 선택했습니다.**
3. **TULIP과 PD4T 데이터를 이용해 RGB, pose, kinematics, VLM을 비교했습니다.**
4. **과제에 따라 유용한 정보와 모델이 달랐습니다.**
5. **최근에는 rationale과 kinematics를 결합해 C3 조건을 확인했습니다.**
6. **최종 목표는 점수만이 아니라, 점수의 근거를 보여주는 임상 보조 도구입니다.**

## 슬라이드별 암기용 대본

### 1. 제목

“안녕하십니까. 서울대학교병원 재활의학과 이영권입니다. 저는 환자분들의 걸음, 균형, 손 기능과 같은 움직임을 평가하고 치료하고 있습니다. 오늘은 그 움직임을 영상으로 정량화하고, AI가 왜 그런 판단을 했는지까지 보여주는 연구를 소개드리겠습니다.”

**기억할 말:** 임상에서 출발한 영상 기반 설명가능 AI입니다.

**넘김:** “먼저 이 주제를 선택하게 된 임상적 배경부터 말씀드리겠습니다.”

### 2. 팀

“저희 팀은 임상팀과 데이터팀이 함께 구성된 융합 팀입니다. 임상팀에서 실제 평가의 필요를 제시했고, 데이터팀에서 이를 영상, pose estimation, kinematics, VLM 분석으로 연결했습니다.”

**기억할 말:** 임상 문제를 데이터 문제로 바꾼 팀입니다.

**주의:** 현재 슬라이드의 ODD 관련 역할 문구는 삭제합니다.

### 3. 임상 문제

“파킨슨병 환자의 속도 감소, 리듬 변화, 좌우 비대칭과 같은 움직임 변화는 임상에서 관찰됩니다. 하지만 그 변화가 정성적 기록에 머무는 경우가 많아, 치료 전후 차이를 수치로 비교하기 어렵습니다.”

**기억할 말:** 보이는 변화가 숫자로 남지 않습니다.

### 4. UPDRS와 H&Y

“임상에서는 UPDRS와 H&Y 같은 척도를 사용합니다. UPDRS는 손가락 태핑이나 보행처럼 세부 동작을 0점에서 4점으로 평가하고, H&Y는 질병의 전반적인 단계를 구분합니다. 세밀한 변화와 전체 기능을 모두 보지만, 관찰과 판단에 의존하는 부분이 남아 있습니다.”

**넘김:** “그래서 저희는 이 관찰을 정량적인 데이터로 바꾸고자 했습니다.”

### 5. 주제 선정

“저희 팀은 단순히 점수를 예측하는 AI가 아니라, 왜 그런 점수가 나왔는지 설명할 수 있는 AI가 필요하다고 판단했습니다. 그래서 파킨슨병 운동기능을 영상 기반으로 정량화하고, 판단 근거를 함께 제공하는 설명가능 AI 시스템을 연구 주제로 선정했습니다.”

**기억할 말:** 점수만이 아니라 점수의 이유입니다.

### 6. TULIP 데이터셋

“먼저 Duke University의 TULIP 공개 데이터셋을 사용했습니다. 파킨슨병의 여러 운동 과제와 임상 라벨이 있고, RGB 영상과 pose 정보를 함께 활용할 수 있어 과제별 비교에 적합했습니다.”

**기억할 말:** 공개 데이터로 재현 가능한 비교를 시작했습니다.

### 7. 데이터 탐색

“데이터를 탐색하면서 파킨슨병군에서 속도, 진폭, 리듬, 좌우 움직임이 어떻게 나타나는지 확인했습니다. 손가락 태핑과 보행은 움직임의 시간 규모와 필요한 특징이 다르다는 점도 확인했습니다.”

**주의:** 집단 차이를 진단적 결론처럼 말하지 않고 탐색적 관찰로 표현합니다.

### 8. 움직임의 수치화

“영상에서 사람의 관절 위치를 추출하고, 누락과 노이즈를 처리한 뒤 속도, 반복성, 주파수, 보폭과 같은 운동학적 특징을 계산했습니다. 이렇게 눈으로 보던 움직임을 숫자로 바꿨습니다.”

**기억할 말:** 영상 → 관절 → 운동 지표입니다.

### 9. 분석 흐름

“전체 흐름은 영상 입력, RGB·skeleton·kinematics 변환, 모델 분석, 점수와 근거 출력의 순서입니다. 모델은 점수를 예측하고, 중요한 프레임과 궤적, 특징을 함께 보여줍니다.”

**넘김:** “그럼 실제로 어떤 정보가 유용했는지 결과를 보겠습니다.”

### 10. 평가 방법

“과제와 입력 표현에 따라 모델을 비교하고, 가능한 경우 환자 단위로 학습과 평가를 나누었습니다. QWK, MAE, exact agreement, 높은 중증도 구간을 보는 GT2+ sensitivity를 함께 확인했습니다.”

**기억할 말:** 환자 단위 분리와 여러 지표로 평가했습니다.

### 11. TULIP 결과

“TULIP에서 손가락 태핑과 같은 미세운동은 kinematic 특징을 사용한 모델이 강했고, 보행과 같은 거친운동은 VLM이 상대적으로 유리했습니다. 손가락 태핑에서는 Random Forest 정확도 0.890, 보행에서는 ChatGPT 5.1 정확도 0.805를 확인했습니다.”

**기억할 말:** 미세운동은 수치 특징, 보행은 시공간 맥락입니다.

### 12. PD4T 결과

“PD4T에서는 보행을 중심으로 제한적인 예비 검증을 진행했습니다. 현재 슬라이드에서는 ChatGPT 5.1 정확도 0.644가 가장 높게 나타났습니다. 이 결과는 최종 임상 성능이 아니라, 다른 데이터에서도 방향성이 재현되는지 확인한 결과로 제시합니다.”

### 13. 시간적 설명

“모델이 영상 전체를 똑같이 본다고 가정하지 않고, 어느 시간 구간이 판단에 영향을 주었는지 확인했습니다. 중요한 프레임을 표시하면 모델이 실제 움직임 변화가 나타난 구간을 보고 있는지 검토할 수 있습니다.”

### 14. 공간적·텍스트 설명

“관절 궤적과 신체 부위별 변화, 텍스트 reasoning을 함께 표시했습니다. 따라서 결과를 점수 하나로 끝내지 않고, 사람이 원본 영상과 대조할 수 있는 근거로 제시합니다. 이 근거가 임상적 인과를 증명한다는 뜻은 아닙니다.”

### 15. 한계

“현재 데이터 규모와 등급 분포, 촬영 조건에는 한계가 있습니다. 포즈 추정 실패와 외부 영상 조건의 영향도 확인해야 합니다. 따라서 더 큰 데이터와 외부 검증, 임상가와의 일치도 평가가 다음 과제입니다.”

**기억할 말:** 연구 결과는 유망하지만 아직 임상 도입 전 검증 단계입니다.

### 16. Hawk I/ParkiCheck 시연

“이제 분석 결과가 실제 사용 흐름에서 어떻게 이어지는지 보겠습니다. 환자는 ParkiCheck에서 손가락 태핑이나 보행 과제를 수행합니다. 기록과 영상이 Hawk I로 전달되고, Hawk I에서 점수와 분석 값, 판단 근거를 확인한 뒤 history에서 변화 기록을 볼 수 있습니다.”

**시연 순서:** ParkiCheck 수행 → 기록 생성 → Hawk I 분석 → 값·근거 확인 → history.

### 17. PD4T Gait와 추가 근거

“최근에는 PD4T Gait에서 임상적 rationale과 kinematic 정보를 추가했습니다. 30명의 환자, 426개 클립을 환자 단위로 나누어 평가했고, rationale은 임상 관찰 단서, kinematics는 gait speed·step 또는 stride length·arm swing 같은 수치 특징을 담았습니다.”

**기억할 말:** 임상 관찰 R과 운동 수치 K를 함께 넣었습니다.

### 18. C0–C3 설계

“C0는 기본 영상 조건이고, C1은 rationale만, C2는 kinematics만, C3는 rationale과 kinematics를 함께 사용한 조건입니다. 같은 모델과 평가 틀 안에서 R과 K를 단계적으로 추가해 정보 결합의 효과를 확인했습니다.”

### 19. 최근 결과

“C0B의 validation QWK는 0.714였고, R+K 조건인 C3BE는 0.773이었습니다. Test QWK는 0.633에서 0.663으로, GT2+ sensitivity는 0.545에서 0.727로 변했습니다. Clinician reference의 validation QWK는 0.795였습니다.

이 결과는 rationale 하나의 효과라기보다, 임상적 관찰 근거와 kinematic 근거를 함께 사용한 evidence-fusion 결과로 해석하겠습니다. ‘이전 결과보다 0.2 향상’이라는 표현은 비교 기준을 확인한 뒤에만 사용합니다.”

**기억할 말:** R+K 결합 결과가 human reference에 가까워졌습니다.

### 20. 결론

“정리하면, 저희는 임상에서 보이지만 기록하기 어려운 움직임을 영상과 운동학 데이터로 정량화했습니다. TULIP과 PD4T에서 과제별 입력과 모델을 비교했고, 최근에는 rationale과 kinematics를 결합해 점수와 근거를 함께 제공하는 방향을 확인했습니다.

Hawk I와 ParkiCheck는 이 연구를 환자 과제 수행부터 전문가 결과 확인까지 연결하는 개념검증 화면입니다. 이 시스템은 임상가를 대체하는 진단 도구가 아니라, 환자의 변화를 반복적으로 기록하고 전문가가 검토할 수 있도록 돕는 보조 도구입니다. 감사합니다.”

## 외우기 어려울 때의 30초 구조

“임상에서는 파킨슨 환자의 움직임 변화가 보이지만, 이를 수치와 근거로 남기기 어렵습니다. 그래서 저희는 TULIP과 PD4T 데이터를 이용해 RGB, pose, kinematics, VLM을 비교하고, 점수뿐 아니라 판단 근거를 제공하는 설명가능 AI를 연구했습니다. 최근에는 rationale과 kinematics를 결합한 C3 조건에서 validation QWK 0.773을 확인했습니다. 최종적으로는 ParkiCheck에서 수행한 과제가 Hawk I에서 분석되고, 전문가가 결과와 근거를 확인하는 흐름을 구현하고자 합니다.”

## 발표 전 최종 확인

- 슬라이드 2의 ODD 문구 삭제
- 슬라이드 2 텍스트 잘림 수정
- 슬라이드 17 제목·부제 겹침 수정
- C0B/C3BE 수치와 clinician reference 확인
- ‘0.2 향상’ 표현 사용 가능 여부 확인
- 최종 모델명·endpoint·프롬프트 확인
- ParkiCheck → Hawk I → history 시연 순서 리허설
- 시연 영상 파일과 발표장 재생 조건 확인
